# PUBLIC_ENC

Bot hosting yang siap digunakan dan uptime 24 jam penuh, hanya memerlukan nomor bot untuk scan/pairing. Bisa kunjungi ke [Wilykun Bot](https://www.Wilykun.net)

Tinggal `npm install` terus `npm start`
